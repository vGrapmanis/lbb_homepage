# Content Checklist

Assets the band owner must provide before going live. These replace placeholders.

---

## Images

- [ ] **Band logo** — SVG preferred, PNG fallback, transparent background
- [ ] **Hero banner photo** — high-res, landscape, min 1920px wide
- [ ] **OG image** — for social sharing, 1200x630px (shows when link is shared on Facebook/Twitter)
- [ ] **Member photos** — square crop, consistent style, min 600x600px each
- [ ] **Album cover art** — one per album
- [ ] **Favicon source** — 512x512px, will generate all sizes from this

## Text Content

- [ ] **Band bio** — 2-3 paragraphs for About section
- [ ] **Member bios** — 1-2 sentences each
- [ ] **Real show/gig data** — dates, venues, cities, ticket links

## External IDs & URLs

- [ ] **Spotify artist ID**
- [ ] **YouTube video ID(s)** — featured video(s) for Media section
- [ ] **Social media URLs:** Facebook, Instagram, Spotify, Deezer, YouTube
- [ ] **Booking/contact email address**
- [ ] **Discography details:** album titles, years, streaming links (Spotify, Deezer, YouTube per album)

## Third-Party Accounts

- [ ] **Mailchimp** — account created + audience form action URL (`USER_ID` and `LIST_ID`)
- [ ] **Google Analytics 4** — Measurement ID (starts with `G-`)
